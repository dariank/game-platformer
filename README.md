# 🎮 Пиксельный Платформер

Добро пожаловать в 2D пиксельный платформер! Это браузерная игра, написанная на чистом JavaScript и Canvas API. 

##  Особенности игры
* **5 уникальных уровней** с возрастающей сложностью.
* **5 игровых персонажей** на выбор (Кошка, Медведь, Зайчик, Лягушка, Мышка).
* **Враги** (крокодилы и динозавры), которых можно побеждать, прыгая им на голову.
* **Система сбора монет** и подсчет очков (Баланс).

## 🕹️ Управление

* **A / Стрелка влево** — Движение влево
* **D / Стрелка вправо** — Движение вправо
* **Space / W / Стрелка вверх** — Прыжок
* **Esc / P** — Пауза

---

## 🛠️ Как запустить игру локально

1. Скачай все файлы проекта (или склонируй репозиторий).
2. Убедись, что все картинки (`spritesheet.png`, `enred_right.png`, `coin.png` и т.д.) лежат в той же папке, что и `index.html`.
3. Открой файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
4. Приятной игры!

## 📂 Структура проекта
* `index.html` — основной HTML-файл.
* `=== Настройка холста ===.txt` — файл с игровым движком и логикой (в дальнейшем лучше переименовать в `.js`).
* `spritesheet.png` — спрайты игровых персонажей.
* `enred_right.png` / `enred_left.png` — спрайты крокодила.
* `enfio_right.png` / `enfio_left.png` — спрайты динозавра.
* `coin.png` — текстура монеты.
* `heart.png` — иконка жизни.
